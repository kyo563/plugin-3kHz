# 待機列整理アプリ わんコメ版 0.1.3

Windows x64向け。共通Bot版0.1.2の更新版です。独立アプリ版1.1.3とは別系統です。

## ダウンロード

**[プラグイン本体をダウンロード](https://github.com/kyo563/plugin-3kHz/releases/download/onecomme-v0.1.3/Taikiretsu-Seiri-App-OneComme-0.1.3-windows-x64.zip)**

`Taikiretsu-Seiri-App-OneComme-0.1.3-windows-x64.zip` をダウンロードし、ZIPを展開してください。
中にある **`sankagata-seiretsu` フォルダ**を、わんコメの **`onecomme\plugins`（プラグインフォルダ）** に配置して使います。
配置先は、わんコメの「…」→「プラグイン」→「プラグインフォルダを開く」から確認できます。

**OBS表示用テンプレートを使う場合：** 同梱の `Taikiretsu-Template.zip` を、わんコメの「…」→「テンプレート」の一覧へドラッグ＆ドロップしてください（`onecomme\templates` 用）。本体ZIPをtemplatesへ置く必要はありません。

※「Source code」のダウンロードは不要です。

## 主な変更

- テンプレートに猫のサムネイルを追加。名称は「待機列整理アプリ｜OBS表示」。
- 説明文を「コメント欄から参加者をリストアップするプラグインです。表示設定はプラグイン管理画面から。」へ変更。
- 管理画面/設定画面の「OBSに追加する」にドラッグ用ボタンを追加。「待機列表示」・1200×600の指定付きでOBSに追加できます。
- わんコメのテンプレート一覧から追加する従来の方法も維持。この方法の初期ソース名は引き続きindex.htmlです。既存ソースの自動改名は行いません。
- Bot設定を設定画面のタブへ統合し、案内文を整理。
- 初回の『自己申告名』登録、わんコメ利用者IDの扱い、メモ表示・保存を改善。
- Bot設定異常時に待機列・OBSまで停止しないよう修正。重複起動要求や長い呼出し名などを改善。

## 導入・更新

1. 更新前に管理画面からJSONバックアップを保存し、わんコメを終了します。
2. 本体ZIPを展開します。必要に応じてWindowsのファイルのプロパティからブロックを解除してください。
3. わんコメのプラグインフォルダ内の `sankagata-seiretsu` を新版へ差し替えます。旧フォルダのバックアップはプラグインフォルダの外に保管してください。
4. わんコメを起動し「待機列整理アプリ」を有効化。管理画面を開き、対象配信を選択します。

`%LOCALAPPDATA%/WaitingListAppOneComme` の待機列・設定・認証保存先は変わりません。この保存先は削除しないでください。内部プラグインIDも維持しています。

サムネイルも更新する場合は、同梱テンプレートをわんコメへ再取り込みしてください。既存のOBSソースは削除せず、表示を確認してから切り替えてください。

## 設定画面の開き方

1. わんコメを起動し、右上の **「…」→「プラグイン」** を開きます。
2. 一覧の **「待機列整理アプリ」** を有効にします。一覧にない場合は、プラグイン画面を再読み込みしてください。
3. 「待機列整理アプリ」の **「URL」ボタン** を押すと、ブラウザーで管理画面が開きます。
4. 管理画面上部の **「設定」** を押してください。OBSの表示や文字、参加キーワードなどを変更できます。Botの接続・通知は、設定画面内の **「Bot設定」タブ** から行います。

変更後は、各項目の保存ボタンを押してください。設定画面を使用する間は、わんコメとプラグインを起動したままにしてください。

## OBSへの追加

わんコメとプラグインを起動し、管理画面/設定画面 →「OBSに追加する」→「OBSへドラッグして追加」をOBSのプレビューへドラッグします。

既存ソースは自動で置き換えません。表示が二重になる場合は旧ソースを非表示にします。OBSを先に起動して表示されない場合は、プラグイン起動後にソースのページを更新してください。

## Botの使い方

1. 自分の配信チャンネルで **@JoinQueueBot** をモデレーターに登録します。
2. プラグインの **設定 → Bot設定 → チャンネルを接続** から、配信者自身のGoogleアカウントで認証します。
3. 「認証結果を確認」を押し、わんコメで対象配信を受信・選択します。
4. 使用する通知を選んで設定を保存し、「接続確認（投稿なし）」→「Botを起動」を押します。

Botは再起動時に自動投稿を始めません。配信開始時に起動してください。Googleのテストユーザーとして許可されたアカウントが必要です。
