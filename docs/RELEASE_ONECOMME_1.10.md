# 待機列整理アプリ・わんコメ版 1.10

## 今回の更新

- **参加人数の変更** — 設定画面で1組あたりの参加人数を3名・2名・1名から選べます。保存すると、対局中・次回・待機列、OBS表示、Botの案内が切り替わります。人数を減らすと対局中から外れた人が待機列の先頭へ移り、人数を増やすと待機列の先頭から対局中の空きを埋めます。参加回数はこの操作では増えません。
- **対局タイムスタンプ** — 管理画面の「対戦した参加者の履歴」で配信を選び、タイムスタンプをコピーするか、UTF-8のテキストファイルとして保存できます。このバージョンでBotの次局通知が投稿された時刻を、YouTube上の配信開始からの経過時間で記録します。

```text
00:00:00 	配信開始
00:12:34 	第1局
00:25:08 	第2局
01:04:21 	第3局
```

書式は `hh:mm:ss` に半角スペースとタブを続け、各行に「配信開始」または「第n局」を出力します。

## セキュリティの更新

- わんコメのプラグインAPIから管理用キーを取得できる経路を廃止しました。このPCのわんコメから管理画面を開く操作を検証し、初回起動時に旧キーを失効させます。
- 共通Botの接続解除では、有効な端末とチャンネルの所有権を確認します。Windows版に同梱する証明書ライブラリも更新しました。
- 脆弱性の報告先は [SECURITY.md](https://github.com/kyo563/plugin-3kHz/blob/onecomme-v1.10/SECURITY.md) に記載しています。

## 導入・更新

1. Windows x64で [プラグイン本体ZIP](https://github.com/kyo563/plugin-3kHz/releases/download/onecomme-v1.10/Taikiretsu-Seiri-App-OneComme-1.10-windows-x64.zip) を展開します。
2. わんコメの「…」→「プラグイン」からプラグインフォルダーを開きます。更新の場合は管理画面からバックアップを保存し、わんコメを終了してから `sankagata-seiretsu` フォルダーを入れ替えます。
3. わんコメを起動し、プラグインの「URL」ボタンから管理画面を開いてください。旧版から更新した場合も、初回はこのボタンから開き直してください。

保存先 `%LOCALAPPDATA%/WaitingListAppOneComme` の設定やデータは引き継がれます。OBSのブラウザソースには、設定画面の「OBS表示設定」から追加できます。付属のテンプレートZIPは、わんコメのテンプレート一覧で使えます。詳細な使い方は同梱のREADMEをご覧ください。

- わんコメのプラグイン一覧では `1.10.0` と表示されます。
