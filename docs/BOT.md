# Botのお知らせ（わんコメ版1.1.0・検証版）

## 利用開始

管理画面の「Botのお知らせ設定」から設定します。初期状態は無効です。わんコメのログインはコメント受信専用で、投稿にはBot専用YouTubeアカウントでのOAuth認証を別途行います。

1. Bot専用のGoogleアカウントを作成し、YouTubeチャンネルと@ハンドルを設定します。
2. [Google Cloud Console](https://console.cloud.google.com/)でプロジェクトを作成します。
3. APIライブラリの「YouTube Data API v3」を有効にします。
4. Google Auth Platformでアプリ情報と連絡先、対象ユーザーを設定します。テスト運用ではBotアカウントをテストユーザーに追加します。APIキーでは投稿できません。
5. クライアントの種類「デスクトップアプリ」でOAuthクライアントを作成し、JSONをダウンロードします。
6. Bot設定画面でJSONを選び、「Googleログインを準備する」を押します。
7. 表示されたGoogleログインのリンクを開き、Bot専用アカウントを選択して投稿権限を許可します。
8. 表示されたチャンネル名を確認し、必要な機能と「Botのお知らせを有効にする」を選び、保存します。
9. わんコメで配信に接続し、管理画面のライブ連携で対象配信を選びます。

認証にはYouTube公式の`youtube.force-ssl`スコープを使用します。Googleの認可画面が示す権限を確認してください。この実装はチャンネル識別・対象配信のチャットID取得・メッセージ投稿に利用します。Google Cloudの画面名称は変わる場合があります。テスト状態のアプリは再認証が必要になる場合があり、一般配布向けに共通OAuthクライアントを提供するには公開・審査等を別途準備します。

## 動作

- 入室案内：初回はNOWが3人そろったとき、「次の対戦へ」では交代後のNOWを通知します。空席名は通知しません。管理削除だけで案内を再投稿しません。
- 順位返信：`@Botのハンドル 順番は？`のように送ります。送信者のチャンネルIDで本人を特定します。NEXT先頭が1番目・第1グループ、4人目は第2グループです。NOW・未登録にはその状態を返します。
- 定期投稿：受付中のみ、10分または30分ごとに設定した参加方法を投稿します。設定変更・配信切替時は間隔を数え直します。
- Bot本人：認証したチャンネルIDで参加・辞退から除外します。停止・接続解除後もIDは保持して除外します。
- 重複・連投：同一メッセージを重複処理せず、同一人物への順位返信は30秒に1回、投稿全体は最短5秒間隔です。送信失敗時は重複投稿を避けるため、そのメッセージを自動再送しません。
- 配信切替・終了・Bot無効化：古い待機投稿は破棄します。送信中のリクエストは取り消せない場合があります。

## 保存・削除

設定とBot認証はアプリ専用保存先の`bot.sqlite3`に保存します。認証情報はWindows DPAPIでユーザーごとに暗号化します。通常の待機列JSONバックアップには含みません。別PCへの移行は再認証が必要です。

「Botの接続を解除」で保存した認証情報を削除します。Google側の認可解除はGoogleアカウントの接続管理から行ってください。全リセットはBot設定・認証を削除しません。完全削除は同梱READMEの手順でアプリ専用保存フォルダを削除します。

## 検証・制約

送信APIを模したテストで通知・順位・タイマー・本人除外・ログインのstate/PKCE・解除の競合を検証しています。実GoogleアカウントでのOAuth、実YouTube配信への投稿、メンバー限定配信は未検証です。Botの視聴・投稿権限、配信の終了、API利用上限などにより送信できない場合は設定画面へエラーを表示します。

この版の認証は利用者自身のOAuthクライアントを必要とします。インストールだけでBotが自動接続される構成ではありません。
