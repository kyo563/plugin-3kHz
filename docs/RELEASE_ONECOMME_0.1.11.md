## このプラグインでできること

わんコメが受信したYouTubeコメントから参加者を登録し、3人ずつの参加順を管理するWindows用プラグインです。

- 「参加希望」で自動登録、「参加辞退」「参加を辞退」で待機列から辞退できます。ゲーム内の名前は `参加希望 『◯◯』` で申告できます。
- 管理画面でドラッグによる並び替え、削除、最後尾への移動、次の対戦への交代、直前の操作の取り消しができます。
- 初回参加優先モードでは、この配信で参加回数が少ない人を優先します。対局中3人・次回3人は追い越しません。
- 対局中・次回・待機人数などをOBSへ表示できます。縦横レイアウト、表示文言、フォント、文字サイズ、背景色・透過度、太字・影を調整できます。
- 設定・待機列・参加回数はPC内に保存し、再起動後も引き継ぎます。今回の参加回数と累計は別々に管理します。
- 共通Botで「次の3人の呼び出し」「本人の参加順への返信」「待機人数・グループ数の定期案内」を個別にON/OFFできます。

コメント取得はわんコメが行います。待機列・OBS表示は、BotやGoogle認証を使わず利用できます。

## 使い方・導入方法

### 1. ダウンロードする

[プラグイン本体ZIPをダウンロード](https://github.com/kyo563/plugin-3kHz/releases/download/onecomme-v0.1.11/Taikiretsu-Seiri-App-OneComme-0.1.11-windows-x64.zip)

`Taikiretsu-Seiri-App-OneComme-0.1.11-windows-x64.zip` を展開して導入します。Windows x64とわんコメが必要です。

### 2. わんコメへ導入する

1. ZIPを展開します。プロパティに「許可する」が表示される場合は、展開前にチェックして適用してください。
2. わんコメの「…」→「プラグイン」→「プラグインフォルダを開く」を選びます。
3. わんコメを終了し、展開した `sankagata-seiretsu` フォルダーを丸ごと配置します。`plugin.js` と `runtime` は分離しないでください。
4. わんコメを起動し、プラグイン一覧で「待機列整理アプリ」を有効にします。
5. プラグインの「URL」ボタンから管理画面を開き、初回セットアップを進めます。設定は管理画面上部の「設定」から変更できます。

本体は**プラグインフォルダー**へ配置します。テンプレート用のZIPとは別です。

### 3. 参加受付を始める

わんコメで対象配信のコメントを受信し、設定の「接続先の配信」を確認して受付中にします。新しい「参加希望」コメントから登録されます。接続先が異なる場合は「別の配信に連携し直す」から選び直してください。

同じ人が再度「参加希望」を送ると、通常の受付中は2回目の希望順に並び直します。連続操作は制限される場合があります。受付停止後の最終組補充では、新しい参加者のみ最後尾へ追加し、登録済みの人の並び順は変えません。

### 4. OBSへ表示する

設定画面の「OBS表示設定」で「OBSへドラッグして追加」を、OBSのプレビューへドラッグします。ソース名は「待機列表示」、標準サイズは1200×600pxです。文言・見た目の変更はプラグイン設定で保存します。

テンプレートを使う場合は、添付の `Taikiretsu-Template.zip` をわんコメのテンプレート一覧へ追加し、そこからOBSへ配置できます。管理画面はOBSのカスタムブラウザドックでも利用できます。

### 5. Botを使う場合（任意）

1. 設定の「Bot設定」の案内に従い、共通の [@参加列整理bot](https://www.youtube.com/channel/UCV3VeoFI04L79MqwuApT-Hg) を自分のチャンネルの標準モデレーターに登録します。
2. 「配信チャンネルを接続」から認証リンクを開き、普段配信しているGoogleアカウントで自分のチャンネルを認証します。
3. 対象配信と通知を選び、「Botを起動」を押します。「Bot稼働中」になれば準備完了です。再起動後は再度起動してください。

視聴者はコメントに `@参加列整理bot` または `@bot` を入れると、自分の参加順を確認できます。Google認証時に警告・アクセス制限が表示される場合があります。メンバー限定配信でのBot投稿は保証していません。

### 既存版から更新する場合

管理画面でバックアップを保存してわんコメを終了し、プラグインフォルダー内の `sankagata-seiretsu` を更新版へ入れ替えてください。旧版の保管先はプラグインフォルダーの外にしてください。保存先 `%LOCALAPPDATA%/WaitingListAppOneComme` を削除しなければ、既存データ・設定を引き継ぎます。OBSソースの作り直しは不要です。

無料版わんコメの利用時は、配信概要欄などへ必要なクレジットを記載してください。詳細は同梱READMEをご確認ください。
