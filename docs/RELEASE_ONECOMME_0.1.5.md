OBS用テンプレートを使う場合は、同梱の `Taikiretsu-Template.zip` を「…」→「テンプレート」の一覧へドラッグ＆ドロップしてください。本体ZIPを `onecomme\templates` に置く必要はありません。「Source code」は実行用ではありません。

## 今回の更新

- Bot認証開始時の通信エラー、認証途中の再起動、期限切れから再試行・再開できるように修正。
- 接続キーの存在だけで認証完了と判定せず、サーバーの認証状態を確認。有効な接続を通信エラーだけで削除しません。
- Bot設定を「モデレーター登録」「チャンネル認証」「通知選択・起動」の3ステップに整理。認証結果は自動確認し、「Botを起動」で変更した通知設定の保存と接続確認も行います。
- 「認証し直す」を追加。確認画面を挟み、接続解除後に新しい認証を開始できます。待機列・履歴・設定は保持します。Google許可の解除は同じアカウントの他のチャンネル・端末にも影響する場合があります。
- 受付停止時、OBSのNOW・NEXTの空き枠を「-」に変更。受付再開時は「参加者募集中」に戻り、両方の文言を設定で編集できます。参加者名は変更しません。

自動テスト740件（Python529件・JavaScript110件・共通バックエンド101件）が成功。Windows配布版の起動・終了、合成わんコメコメント受信、OBS用データ、受付状態と文言の連動、ZIP取得・再起動復元を隔離保存先で確認しました。今回の修正後の実Google認証・実チャット投稿・OBS実描画は未検証です。

認証復旧用のサーバーコードも本番へ反映済み。同じ端末キーで未完了の認証リンクを再発行できることを、Google認証・投稿を行わない合成試行で確認しています。

## 更新方法

1. 管理画面でJSONバックアップを保存し、わんコメを終了します。
2. 新しい本体ZIPを展開して、プラグインフォルダの `sankagata-seiretsu` を差し替えます。旧フォルダを保管する場合は、プラグインフォルダの外に置いてください。
3. わんコメを起動し、「待機列整理アプリ」を有効にします。

保存先 `%LOCALAPPDATA%\WaitingListAppOneComme` は変更しません。このフォルダを削除しなければ待機列・設定・認証情報を引き継ぎます。独立版と旧リリースは変更しません。

## 設定画面の開き方

わんコメの「…」→「プラグイン」→「待機列整理アプリ」の「URL」から管理画面を開き、上部の「設定」を押してください。「基本設定」「OBS表示設定」「Bot設定」をタブで切り替えられます。

## Botの接続

初回は @JoinQueueBot を自分のチャンネルの標準モデレーターに登録し、Bot設定から普段配信するGoogleアカウントとチャンネルを認証します。対象配信と通知を確認して「Botを起動」を押し、「Bot稼働中」と表示されれば完了です。次回以降は有効な認証・通知設定を引き継ぎますが、再起動や配信変更後は「Botを起動」が必要です。

認証途中で進めなくなった場合は「認証を再開・やり直す」。それでも復旧しない場合や認証済みチャンネルを選び直す場合は「認証し直す」を使用してください。Googleの審査・認証上限・アカウント側のアクセス拒否を回避する機能ではありません。限定配信でのBot投稿対応は今回の更新に含みません。

待機列・OBS表示はBot認証なしでも利用できます。コメント取得は引き続きわんコメが行います。
