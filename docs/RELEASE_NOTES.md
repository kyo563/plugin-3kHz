# 0.1.0-preview.21 — 参加型整列プラグイン Windows検証版

初回のGitHub配布用ZIPです。ZIPを完全展開し「参加型整列プラグイン.exe」を起動してください。

- README.md / README.txtに導入、OBS設定、管理、縦横・行編集、名前、概要欄文、更新・バックアップ・削除手順を統合。
- 3人固定の待機列管理、手動追加、順番変更、参加回数・総対戦回数、名前の編集。
- OBS透過表示、縦横共通サイズ、自由な行編集、名前4方式・フォント指定。
- 概要欄コピペ用の文章を編集・保存・コピー。
- 外部コメント受信API（参加希望 『名前』に対応）。特定チャット製品との連携は別途必要。

未署名・インストーラーなし。YouTubeコメント自動取得とコメントBotは含みません。OBS/Edge長時間併用、クリーンPCの受入試験は未完了です。

以下はローカル開発版の履歴です。「未公開」は各版を作成した当時の状態を示します。

## 設定リセット（preview.12・未公開）
設定画面最下部の「設定をリセットする」で確認画面を開き、「本当にリセットする」を押すと表示設定を初期値へ戻して保存します。「キャンセル」またはEscなら変更しません。未保存の編集は確定時に破棄します。待機列・対戦回数・参加者名・登録済みフォントファイルは保持します。OBS側のソース寸法は自動変更しないため、必要に応じ480×600へ合わせてください。

## 縦横切り替えと行編集（preview.14）
配置セットは文字配置だけを切り替え、幅・高さは共通で維持します。既存の保存サイズも維持します。一度OBSと表示領域を合わせた後は、設定で縦/横を選び保存するだけで反映します。縦向きは全体の編集欄、横向きは受付/NOW/NEXT/QUEUE各列の編集欄でEnter・Backspaceを使用できます。各配置の編集内容は独立保存されます。空欄は非表示です。行が多いと文字を自動縮小します。従来の「自由編集」も維持します。


## 行・列の削除（preview.15）
行編集の[受付]や[NOW見出し]などを削除して保存すると、OBSにも表示しません。行を詰めるときは改行ごと削除します。行間調整の空行は維持します。横向きの列全体を空欄にすると、その列も詰めます。


## preview.16（未公開）

## 名前を指定して参加（preview.17）
「参加希望 『PlayerABC』」で括弧内を申告名として登録します（最大32文字、前後空白除去）。「参加希望」だけでも参加できます。名前指定が空欄・閉じ括弧なしの場合は通常の参加として扱います。辞退は従来どおり「参加辞退」。OBSでは「申告名のみ」または申告名を含む表示方式を選んでください。配信者の手動指定は優先されます。外部アプリからコメントを受信する仕組みは引き続き必要です。


## 概要欄コピペ用（preview.18）
管理画面の「その他（設定・バックアップ）」→「概要欄コピペ用」を開くと、参加・辞退・表示名変更の案内文を編集できます。「文章を保存」で次回用に保存、「文章をコピー」で現在の入力内容をクリップボードへコピーします。コピーだけでは保存しません。コピーが利用できない環境では本文を選択するのでCtrl+Cを使ってください。待機列のリセットでは文章を保持し、JSONバックアップにも含めます。「保存済みの文章を読み込む」は未保存の編集を置き換えます。
