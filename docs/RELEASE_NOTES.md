# 参加型整列プラグイン 1.1.0

YouTubeの公式APIからライブコメントを受信できるようになりました。従来は別の連携ソフトが必要でしたが、管理画面で配信URLとYouTube Data API v3のAPIキーを入力すると参加・辞退コメントを処理します。

## 使用方法
1. 旧アプリを終了します。
2. 配布元を確認したZIPのプロパティで「許可する」があれば適用し、すべて展開します。
3. 新しい「参加型整列プラグイン.exe」を起動します。同じWindowsユーザーの標準保存先では待機列と設定を引き継ぎます。
4. 管理画面上部の「YouTubeコメント受信」に配信URLとAPIキーを入力し「コメント受信を開始」を押します。
5. 「受信中」「受付中」を確認してから「参加希望」を送ってください。

指定名の「参加希望 『名前』」、「参加辞退」「参加を辞退」に対応します。約10秒以上の遅延があります。接続前の履歴は反映しません。状態変更後40秒間の連続操作制限は従来どおりです。

## 接続と保存
APIキーは停止・終了で破棄され、再接続時に再入力します。Google CloudでYouTube Data API v3を有効にしてください。利用上限、権限エラー、配信終了時は理由を表示して受信を停止します。手動管理も利用できます。

## 配布と確認範囲
Windows 11 x64のZIP版です。ChromeやPythonの追加導入は不要です。Microsoft Edge WebView2 Runtimeを使用します。未署名で、インストーラーは含みません。
Python256テスト、画面操作16テスト、HTTP検証、配布ZIPからのWindows起動・画面読み込み・終了・隔離データ削除を確認しました。
実際のAPIキーとYouTubeライブ配信での受信、OBS/Edge長時間併用、クリーンPC、すべての表示倍率は未確認です。
