# 参加型整列プラグイン 1.0.0

現行機能を完成版として正式公開しました。アプリ・配布ファイル・READMEの開発版表記を正式版に更新しています。

## 主な機能

- 3人固定の待機列管理、手動参加、対戦進行、並び替え
- 参加回数・総対戦回数、初回参加優先モード、操作の取り消し
- OBSの透過表示、縦横配置、行編集、文字・フォント・名前表示の設定
- 概要欄用文章の編集・保存・コピー、JSONバックアップ・復元
- 外部コメント受信API、名前付き参加希望（参加希望 『名前』）
- 「待」の麻雀牌アイコン

## 導入と更新

Sankagata-Seiretsu-Plugin-1.0.0-windows-x64.zipをすべて展開し、「参加型整列プラグイン.exe」を起動してください。README.txtに導入・利用・削除の手順を記載しています。
更新時は古いアプリを終了してから新しいexeを起動してください。同じWindowsユーザーの標準保存先なら既存の待機列・設定を引き継ぎます。

## 対応範囲

Windows 11 x64向けのZIP版です。未署名で、インストーラーは含まれていません。
YouTubeコメントの自動取得は別途連携が必要です。コメントBotは搭載していません。
正式版の指定は現在の機能範囲に対するものです。OBS/Edgeの長時間併用、クリーンPC、すべての表示倍率・外部チャット製品を検証済みとするものではありません。
