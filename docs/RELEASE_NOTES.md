# 参加型整列プラグイン 1.1.2

## 追加・改善
- 管理画面に待機者全員を参加順で一覧表示。先頭3人に「次」の目印を付け、ドラッグ＆ドロップで並べ替えできます。
- 参加者の各行に「編集」「削除」を配置。表示用の名前を保存し、削除時は対象名を確認します。参加回数と記録済みの対戦履歴は残ります。
- 「次の対戦へ」をNOW一覧の下へ独立配置し、黄色の大きなボタンに変更しました。
- 設定にOBS文字色の一括変更を追加。プレビューで確認し、「保存してOBSに反映」で保存します。
- 実際に対戦した参加者の履歴を追加。初対戦順・重複なしの一覧、配信内参加回数、ユニーク人数、コピー、過去の配信選択に対応します。
- コメントの連続操作制限を設定から0～3600秒に変更できます。初期値40秒、0秒は無効。全リスナー共通で参加希望・辞退の双方に適用し、再起動後も保持します。

## 履歴の記録
「次の対戦へ」を押すと、その時点のNOWを記録します。最後の対戦後も押してください。同じ対戦の参加者はNOWの並び順です。
次の配信は「新しい配信の履歴を開始」で区切ります。配信URLの変更では自動で区切りません。累計参加回数や待機列は変わりません。
導入前の参加順は復元できません。履歴はバックアップに含まれ、全リセットで削除されます。

## 導入・更新
旧アプリを終了します。配布元を確認したZIPのプロパティで「許可する」があれば適用し、すべて展開して「参加型整列プラグイン.exe」を開きます。_internalは削除しないでください。
同じWindowsユーザーの標準保存先では待機列・設定を引き継ぎます。更新前にバックアップを保存してください。新機能を使ったデータは旧版へ戻さず、更新版で扱ってください。

## YouTubeコメント受信
管理画面で配信URLとYouTube Data API v3のAPIキーを入力し、「コメント受信を開始」を押します。「受信中」「受付中」になってから投稿されたコメントが対象です。約10秒以上の遅延があります。キーは停止・終了時に破棄します。
APIキー方式のため、メンバー限定・非公開配信を扱うGoogleログイン認証は未実装です。実際のYouTube配信での受信は未検証です。

## 配布範囲
Windows 11 x64の未署名ZIP版。Chrome・Python・OBS追加プラグインは不要で、Microsoft Edge WebView2 Runtimeを使用します。
OBS/Edgeの長時間併用、クリーンPC、すべての表示倍率は未確認です。
