# 待機列整理アプリ・わんコメ版 1.11

## OBSの対局カウンター

- 「現在の対局数」「対戦済み人数」を、待機列表示とは別々のOBSブラウザソースとして追加できます。「設定」→「OBS表示設定」→「OBSに対局カウンターを追加」から、使いたいソースをOBSへドラッグしてください。手動で追加する場合の推奨サイズは600×100pxです。
- 対局中欄に参加者がいる間は「現在n局目」を表示します。「対戦済み人数」には、その配信で確定した対局に参加した人を重複なく数えます。管理画面で「直前の対局確定を取り消す」と、集計も戻ります。取り消せるのは確定後に待機列の更新や別の操作が入る前までです。
- 表示文言に `{round}` や `{unique}` を差し込めます。設定画面で表示例を確認し、初期文言にも戻せます。
- フォント、文字サイズ、文字色、背景色、背景の透過度、太字、影、自動縮小は、待機列の「表示を細かく調整する」からまとめて変更できます。項目別のフォントは「OBS：待機人数」が両カウンターに適用されます。

## セキュリティ

- Windows版の実行環境をPython 3.14.10、OpenSSL 3.5.9、SQLite 3.54.1に更新しました。ビルド時に使うsetuptoolsも修正版に更新しました。
- カウンターの表示用APIは表示文言と見た目に必要な情報を返します。外部サイトからの読み込みを制限し、設定の保存や対局の取り消しには管理認証が必要です。
- 脆弱性の連絡方法は [SECURITY.md](https://github.com/kyo563/plugin-3kHz/blob/onecomme-v1.11/SECURITY.md) をご覧ください。

## 導入・更新

1. Windows x64で [プラグイン本体ZIP](https://github.com/kyo563/plugin-3kHz/releases/download/onecomme-v1.11/Taikiretsu-Seiri-App-OneComme-1.11-windows-x64.zip) を展開します。
2. わんコメのプラグインフォルダーを開き、更新の場合は管理画面からバックアップを保存して、わんコメを終了してから `sankagata-seiretsu` フォルダーを入れ替えます。
3. わんコメを起動し、プラグイン一覧の「URL」ボタンから管理画面を開きます。わんコメ内の識別番号は `1.11.0` です。

保存先 `%LOCALAPPDATA%/WaitingListAppOneComme` の設定やデータは引き継がれます。公開ZIPのSHA-256は添付の `SHA256SUMS.txt` で確認できます。
