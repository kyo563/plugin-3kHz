# 参加型整列プラグイン — 導入・利用ガイド

Windows用の参加型配信向け待機列管理アプリです。1グループ3人で、現在の参加者・次の参加者・待機人数をOBSに表示します。

**開発版1.1.0ではYouTubeコメント受信を追加しました。** 管理画面上部に配信URLとAPIキーを入力し、「コメント受信を開始」を押します。[設定と制約](YOUTUBE_CHAT.md)を確認してください。公開版1.0.0にはこの機能はありません。

## 1. 動作環境

- Windows 11 / x64（ARM版・Windows 10は動作未確認）
- Microsoft Edge WebView2 Runtime、.NET Framework 4.8相当の環境
- 配信表示に使うOBS Studio
- インターネットはダウンロード・外部連携時に使用。手動管理とOBSへのローカル表示はPC内で動作します。

Chrome、Python、OBS専用プラグインのインストールは不要です。独立したWindowsアプリなので、OBSのプラグインフォルダーへコピーしないでください。

WebView2が不足する場合はMicrosoft公式から導入します：
https://developer.microsoft.com/microsoft-edge/webview2/

## 2. ダウンロード・起動

1. GitHubのReleasesを開きます： https://github.com/kyo563/plugin-3kHz/releases
2. 利用したいバージョンの「Assets」から、名前が「Sankagata-Seiretsu-Plugin-」で始まるwindows-x64.zipをダウンロードします。GitHubが自動生成する「Source code」は開発用で、そのまま起動できません。
3. このプロジェクトから取得したZIPの「プロパティ」→「全般」で、下部に「許可する」がある場合はチェックして「適用」します。その後、ZIPを右クリックして「すべて展開」します。
4. 展開した「参加型整列プラグイン」フォルダーの「参加型整列プラグイン.exe」を起動します。
5. README.txtはメモ帳などで開けます。exeだけを移動せず、_internalを含むフォルダー全体を保管してください。

このバージョンは未署名です。Windowsが発行元を確認できない旨を表示する場合があります。入手元とリリースページ記載のSHA-256でファイルを確認し、組織の実行制限がある場合は管理者へ確認してください。

「Failed to resolve Python.Runtime.Loader.Initialize」が出る場合は、ダウンロードしたDLLがWindowsでブロックされている可能性があります。配布元を確認したZIPに上記の「許可する」を適用し、新しいフォルダーへ展開し直してください。展開済みファイルには遡って反映されません。

チェックサム確認例（PowerShell）：

```powershell
Get-FileHash -Algorithm SHA256 .\Sankagata-Seiretsu-Plugin-1.0.0-windows-x64.zip
```

起動済みのときに別バージョンのexeを開いても、既存アプリが表示されます。更新時は先に古いアプリを終了してください。

## 3. 初回のOBS設定

1. アプリ上部の「OBSに追加する」を開き、「表示URLをコピー」を押します。
2. OBSの「ソース」の＋から「ブラウザ」を追加します。
3. 「ローカルファイル」をオフにして、コピーした表示URLを貼り付けます。
4. 初期設定では幅480・高さ600に合わせます。変更済みの場合はアプリに表示される寸法を使います。
5. OBSのプレビューで位置と大きさを調整します。背景は透過し、文字だけが表示されます。

次回から同じソースを使えます。アプリを起動してからOBS表示を確認してください。
「管理用URL」は操作権限を含むため、配信用ブラウザソースには貼り付けません。

OBS内で管理する場合は「OBSに追加する」→「他の画面で管理」にある管理用URLをコピーし、OBSのカスタムブラウザドックに登録します。Edgeでも管理用URLを開けます。管理URLや接続キーは第三者に共有しないでください。

## 4. 毎回の基本操作

1. アプリを起動します。待機列と参加回数は自動復元されます。
2. 「受付を開始／終了」で受付を切り替えます。
3. 「参加者の追加・検索」を開き、名前を入力して参加者を追加します。
4. 対戦が終わったら「次の対戦へ」を押します。
5. 配信終了後は「アプリを終了」→「終了する」を押します。

| 表示・操作 | 意味 |
|---|---|
| NOW | 現在の参加者（最大3人） |
| NEXT | 待機列の先頭3人 |
| QUEUE | 待機列の4人目以降 |
| nグループ/n人待機中 | NOWを除きNEXTを含めた待機合計。3人で1グループとして切り上げ |
| 総対戦回数 | NOWに実参加者がいる状態で「次の対戦へ」を押した回数 |
| 初回参加優先モード | 参加回数が少ない方を優先するモード。ONは緑色とチェックで表示 |
| 直前の操作を戻す | 直前の手動操作を1回取り消す。別の状態変更後などは使用不可 |

参加者の「編集」で申告名を変更できます。右クリックで削除や回数補正等を行えます。NEXT・QUEUEはドラッグで順番変更できます。
手動追加で同じ名前を再入力すると別人扱いです。再参加時は検索結果などで確認した同じ参加者IDを指定すると参加回数を引き継げます。

## 5. OBSの見た目を変更

上部の「設定」で編集し、黄色の **「保存してOBSに反映」** を押します。編集だけでは本番OBSへ反映されません。

- 縦向き／横向きは文字の並びを切り替えます。幅・高さは共通で維持するため、配置切替のたびにOBS側を変更する必要はありません。
- 縦向きは全体、横向きは受付・NOW・NEXT・QUEUEの各列を編集できます。Enterで改行・空行を追加し、Backspaceで削除します。
- [NOW1]などは自動更新欄です。名前を直接入力せず、この欄を残すと対戦交代に追従します。
- 見出しを消す場合は[受付]や[NOW見出し]を削除します。空白も詰めたい場合は改行ごと削除してください。横向きの列全体を空欄にするとその列も詰めます。
- 文字サイズやフォントを一括・項目別で変更できます。縦横の通常配置は高さが不足すると文字を自動縮小し、長い名前は省略します。
- PCのTTF・OTF・WOFF・WOFF2を追加できます。元ファイルとOS設定は変更せず、アプリ内にコピーします。TTCは非対応です。
- 最下部の「設定をリセットする」は確認後に表示設定を初期化します。待機列・対戦回数・登録済みフォントは消しません。

表示名は「YouTubeアカウント名のみ」「申告名のみ」「アカウント名／申告名」「申告名／アカウント名」の4種類です。名前を指定して参加する場合の名前をOBSに出すには、申告名を含む表示方式を選びます。
サンプルプレビューは架空の参加者、「現在の待機列」は実際の参加者です。

## 6. コメントによる参加（外部連携を用意した場合）

**アプリを起動するだけではYouTubeのコメントは届きません。** 1.1.0では管理画面のYouTubeコメント受信で接続してください。 連携仕様はリポジトリの[外部入力仕様](EXTERNAL_INPUT.md)を参照してください。特定チャット製品との動作保証はまだありません。

- 参加：参加希望
- 名前を指定して参加：参加希望 『◯◯』（最大32文字）
- 辞退：参加辞退 または 参加を辞退

参加・辞退の状態変更後は40秒間の連続変更制限があります。登録済みの方が再び参加希望を送ると、制限終了後に待機列の最後尾へ移動します。参加後の名前変更は配信者に依頼してください。配信者が手動指定した名前を優先します。

## 7. 概要欄に貼り付ける文章

管理画面下部の「その他（設定・バックアップ）」を開くと「概要欄コピペ用」が展開されています。
文章を編集して「文章を保存」を押すと、次回も保持します。「文章をコピー」で配信の概要欄へ貼り付けられます。コピーだけでは保存しません。
見出しを押すと折りたためます。通常の待機列リセットでは文章を保持します。

## 8. 保存・更新・バックアップ

データは標準で %LOCALAPPDATA%\WaitingListApp に保存されます。これは互換性のために維持している内部名です。
更新は古いアプリを終了し、新しいZIPを別フォルダーへ展開して起動します。同じWindowsユーザー・標準保存先なら保存データを引き継ぎます。

「その他」→「バックアップを保存」でJSONを保存できます。待機列・回数・表示設定・概要欄の文章等を含みます。復元は現在のデータを上書きするため、先に現状のバックアップを保存してください。
フォントファイル本体・認証キー・ポート・OBS設定はJSONに含みません。別PCではフォントを再登録してください。

## 9. 終了・削除

「受付を終了」は参加受付を止める操作です。アプリ自体を閉じるには「アプリを終了」を使います。

ZIP版の本体だけを削除する場合は、アプリを終了して展開フォルダーを削除します。保存データは残ります。
保存データも完全に削除する場合は、必要なバックアップを取って終了した後、展開フォルダーでPowerShellを開き、次を実行します。**待機列・回数・設定・取り込んだフォント等は元に戻せません。**

```powershell
& '.\参加型整列プラグイン.exe' --uninstall-data
```

成功後に展開フォルダーを削除します。本アプリの所有データだけを対象とし、OBS設定・Edgeプロファイル・共有WebView2/.NETは削除しません。所有確認に失敗したデータや利用者が別に保存したバックアップは削除しません。
OBSへ自分で追加したブラウザソース・ドックは、不要になった時点でOBSから削除してください。
今回の配布にWindowsのアプリ一覧から削除するインストーラーは含まれていません。

## 10. 困ったとき

- 新機能が見えない：古いアプリを終了してから新しいexeを起動します。OBSドックやEdgeの管理画面も再読み込みします。
- OBSに出ない：アプリ起動、表示URL、ブラウザソースの幅・高さ、ソースの表示状態を確認します。
- 編集が反映されない：黄色の「保存してOBSに反映」を押します。
- 参加コメントが反映されない：外部アプリとの接続が必要です。手動追加が動くか、受付状態、40秒制限も確認します。
- ポートが使用中：他アプリを強制終了せず、アプリの案内または起動引数 --port 8081 で別のポートを指定します。OBSのURLも合わせます。
- 起動できない：ZIPを完全展開したか、_internalがあるか、WebView2環境を確認します。

不具合報告先： https://github.com/kyo563/plugin-3kHz/issues
バージョン、Windows/OBSのバージョン、操作手順、表示されたエラーを添えてください。管理URL・キー・個人情報を含むDBは公開しないでください。
