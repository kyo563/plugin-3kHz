## 今回の更新

NOW（対戦中）の参加者を、次の3通りで操作できます。

- **移動**：待機列の希望する位置へドラッグ＆ドロップします。待機列の下の余白へ落とすと最後尾へ移動します。
- **削除**：参加者の「削除」ボタン、または右クリック→「削除」で取り除きます。
- **最後尾へ移動**：参加者を右クリック→「待機列の最後尾へ移動」を選びます。

いずれも、空いたNOW枠には**元の待機先頭（NOWを含めて4人目）**を自動補充します。残りのNOW・NEXT・待機列も隙間なく前詰めになります。受付停止中も同じ動作です。

移動した人を待機先頭へ入れる場合も、元の待機先頭を先にNOWへ補充します。待機者がいない場合、移動した人はNOWに残ります。削除で全参加者が3人未満になった場合は、末尾だけが空き枠になります。

移動・削除・補充では参加回数や対戦履歴を加算しません。「直前の操作を戻す」で操作と補充をまとめて取り消せます（その後にコメントによる変更・別操作・再起動が入ると取り消せません）。旧版でNOWに空き枠が保存されていた場合も、復元時に待機先頭から補充します。

## 更新方法

1. 管理画面からJSONバックアップを保存し、わんコメを終了します。
2. 新しい本体ZIPを展開し、プラグインフォルダの `sankagata-seiretsu` を差し替えます。旧フォルダはプラグインフォルダの外へ保管してください。
3. わんコメを起動し、「待機列整理アプリ」を有効にします。

保存先 `%LOCALAPPDATA%\WaitingListAppOneComme` は変わりません。このフォルダを削除しなければ待機列・履歴・設定・Bot接続情報を引き継ぎます。Botを利用する場合は起動後に接続先と通知設定を確認し、「Botを起動」を押してください。
