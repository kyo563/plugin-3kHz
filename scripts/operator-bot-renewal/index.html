共通Botの再認証準備（運営者専用）

この画面はご自身のPC内だけで動きます。新しい一回用の設定キーを作成し、Cloudflareの設定を更新します。Googleのクライアントシークレットを作り直す操作ではありません。

値はチャットへ送らないでください。ページを再読み込み・閉じると作成した値は失われます。Google認証を完了するまで開いたままにしてください。

Cloudflareの joinqueue-bot-backend → Settings → Variables and Secrets で、BOT_AUTH_SETUP_HASH を編集します。種類を Secret のまま、コピーしたハッシュをValue欄へ貼り付けてDeployで保存してください。他のSecretは変更しません。

保存できたら「一回用ハッシュを登録しました」とお知らせください。こちらで短時間だけ認証入口を開きます。

入口を開いた後、共通Botの運営者認証画面へ進み、設定キーを貼り付けます。Googleでは joinqueue.bot@gmail.com / @JoinQueueBot を選び、ご自身で承認してください。普段配信するアカウントではありません。

Google認証が成功するまでは、古いBot認証情報を保持します。この操作ではBotの起動・投稿は行いません。待機列・設定・配信者の接続は変更しません。
