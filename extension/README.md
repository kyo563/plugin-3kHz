# 旧Chrome拡張版 参考資料

このディレクトリには、過去に検討・試作したChrome拡張版の実装が残されています。  
現在の本流仕様ではありません。

## 参考として残す要素

- 参加希望コメントの検知
- 同一ユーザーの重複登録防止
- 参加回数の考え方
- 表示名の安全処理
- DOM変更に対する注意点

## 現行仕様では採用しない要素

- Chrome拡張としての配布
- YouTubeページへのUI注入
- メモリ保持のみ
- 固定キーワード
- 旧UI上での次回/次々回表示

## 旧実装の確認手順（参考）

旧実装の挙動確認が必要な場合のみ、次の手順を使ってください。

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `extension` フォルダを選択
5. YouTube配信ページを開く（またはリロード）

※ 上記は旧実装の確認用であり、現行開発フローではありません。
