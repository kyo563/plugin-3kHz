1. 標準モデレーターに登録する

共通Bot：JoinQueueBotチャンネルを見る
  1. 配信するチャンネルのYouTube Studioを開く
    YouTube Studioを開く（別タブ）。普段配信しているGoogleアカウントでログインし、設定対象が自分の配信チャンネルであることを確認します。
  2. 左側メニューの「設定」をクリック
    YouTube Studioの左下にある歯車マークの「設定」を開きます。
  3. 「コミュニティの管理」→「ユーザー管理」を開く
    設定画面内の「コミュニティの管理」を選び、「ユーザー管理」タブを開きます。
  4. 「標準モデレーター」欄にBotのURLを貼り付ける
    「管理モデレーター」ではなく「標準モデレーター」の入力欄を使います。下のURLをコピーして貼り付け、候補に表示されたJoinQueueBot（@JoinQueueBot）を選択します。
  5. 「保存」をクリック
    JoinQueueBotが標準モデレーター欄に追加されていることを確認し、設定画面の「保存」を押します。URLを入力しただけでは完了しません。
  6. このプラグインの画面に戻る
    下の「2. 配信チャンネルを認証する」へ進みます。モデレーター登録だけではBotは起動しません。

登録済みの場合は、そのまま次の項目へ進んでください。

2. 配信チャンネルを認証する

  1. 「配信チャンネルを接続」を押すと、認証リンクと照合番号が表示されます。
  2. 「ブラウザーでチャンネルを認証する」を開き、照合番号を確認します。
  3. 開いたページの「Googleでチャンネルを確認する」を押し、普段配信するGoogleアカウントとチャンネルを選びます。Googleの同意画面でアプリ名・要求される権限を確認して許可します。
  4. 認証が完了したらこの画面へ戻り、「認証結果を確認」を押します。

配信チャンネルの確認にはYouTubeの読み取り専用権限を使用します。チャット投稿は共通Botが行います。

認証できないとき

普段配信しているアカウント・チャンネルを選んだか確認してください。認証の取消やリンクの期限切れが起きた場合は、下の「配信チャンネルの変更・接続解除」から解除し、もう一度接続してください。アクセスが拒否される場合は、表示されたエラーを運営へお知らせください。OBSドック内で認証できない場合は、認証リンクを通常ブラウザーで開いてください。

3. 対象の配信に接続する

  1. わんコメで対象のYouTube配信に接続します。
  2. 下の対象配信を確認します。異なる場合は「別の配信に連携し直す」を開き、配信を選んで「この配信に連携する」を押します。
  3. 認証したチャンネルの配信であることを確認し、「接続を確認」を押します。

基本設定で接続先の配信を確認・変更する

配信前で接続確認が通らない場合は、チャンネル認証まで済ませておき、配信時に再確認してください。

4. 通知選択

チャンネル認証が完了すると通知を選択できます。

5. Botを起動する

チャンネル認証・対象配信の接続確認・通知設定が終わったら「Botを起動」を押します。「Bot稼働中」になれば準備完了です。

停止・再起動時の動作

再起動時は停止状態です。停止・設定変更時に未送信通知を破棄します。送信済み・送信中の投稿は取り消せません。配信変更や接続切断時も停止します。

配信チャンネルの変更・接続解除

変更する場合は解除後に別の配信チャンネルを接続してください。共通Bot自体は変更しません。待機列・履歴は保持します。サーバーで接続を失効できない場合はキーを残し、通信復旧後にやり直します。

配信チャットに投稿しますか？

選択中の配信に「JoinQueueBot 接続テスト」を1件投稿します。登録の必須手順ではありません。投稿は取り消せません。
