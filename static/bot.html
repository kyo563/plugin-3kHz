GoogleでBot専用アカウントにログインする

認証情報はWindowsのユーザーごとに暗号化して保存し、JSONバックアップや配布ZIPには含めません。接続解除でこのPCに保存した認証情報を削除します。Google側の許可はGoogleアカウントの接続管理から解除できます。

初回のOAuth作成手順

  1. Google Cloud Consoleでプロジェクトを作り、YouTube Data API v3を有効にします。
  2. Google Auth Platformでアプリ情報・連絡先と対象ユーザーを設定します。テスト運用ではBotアカウントをテストユーザーに登録します。
  3. クライアントを作成し、種類を「デスクトップアプリ」にしてJSONをダウンロードします。APIキーではありません。
  4. 上でJSONを選択してログインを準備し、表示されたリンクからBot専用アカウントで許可します。接続したチャンネル名を確認してからBotを有効にしてください。

テスト状態のOAuthは再認証が必要になる場合があります。配布者共通のログインを提供する場合はGoogleの公開・審査手続きが別途必要です。APIの利用上限や配信側の投稿制限により送信できない場合は、接続状況に表示します。
