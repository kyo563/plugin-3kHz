APIキーの準備・使い方

Google CloudでYouTube Data API v3を有効にし、認証情報からAPIキーを作成します。APIの制限はYouTube Data API v3を指定してください。ブラウザ参照元の制限付きキーは使用できません。

キーはこのアプリの接続中だけ保持し、ファイルやバックアップには保存しません。停止後・再起動後は入力し直します。公開ライブ配信向けです。

接続前のコメントは読み飛ばします。参加後は設定した秒数の間、辞退などの連続操作が制限されます。受信件数は待機列への追加人数とは異なります。APIの利用上限に達した場合は受信を停止します。

公式APIでハンドルを取得できない場合は、YouTubeの表示名を使います。コメントの投稿は行いません。

        参加者の追加・検索

        今回：現在の配信で対戦を終えた回数。累計：過去の配信を含む回数です。「次の対戦へ」で加算し、参加登録・辞退・自動補充では加算しません。履歴の累計は一覧取得時点の値です。

        初回は名前だけで追加できます。同じ名前の方は別人として扱います。再参加に備えて検索結果のIDを控えておくと、同じIDで回数を引き継げます。

          参加者を右クリックすると回数補正などを選べます。検索結果はキーボードでも操作できます。
