# 待機列整理アプリ（仮称）

YouTubeライブの参加希望コメントを整理し、配信者が参加型企画を運用しやすくする **ローカルWebアプリ** です。

## 現行方針（MVP）

- 麻雀専用ではなく、参加型ゲーム全般を対象
- 主対象は **視聴者3人 + 配信者1人** の参加型構成
- Chrome拡張ではなく、ローカルWebアプリとして開発
- OBSにはブラウザソースで表示（`/overlay`）
- 管理画面（`/control`）とOBS表示画面を分離
- 状態はSQLiteに保存し、再起動時に復元

## 旧Chrome拡張実装について

`extension/` 配下の実装は旧アプローチの資料です。

現在の正式方針は、Chrome拡張ではなく、ローカルWebアプリ + OBSブラウザソース + 管理画面 + SQLite保存です。

実装時に `extension/` 配下を現行仕様として扱わないでください。

## 旧実装から転用する設計資産

旧Chrome拡張実装からは、次の設計資産のみを転用します。

- 参加回数（`participation_count`）の考え方
- 参加順管理（先着順・並び直し）
- 重複処理（同一ユーザー再参加時の扱い）
- 表示名安全処理（長文・表示崩れ対策）
