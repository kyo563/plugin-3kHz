# 待機列整理アプリ（仮称）

YouTubeライブの参加希望コメントを整理し、配信者が参加型企画を運用しやすくする **ローカルWebアプリ** です。

## 現行方針（MVP）

- 麻雀専用ではなく、参加型ゲーム全般を対象
- 主対象は **視聴者3人 + 配信者1人** の参加型構成
- Chrome拡張ではなく、ローカルWebアプリとして開発
- OBSにはブラウザソースで表示（`/overlay`）
- 管理画面（`/control`）とOBS表示画面を分離
- `/control` は実運用の配信者操作画面
- 状態はSQLiteに保存し、再起動時に復元
- OBS表示ラベルは `NOW / NEXT / QUEUE`

## チャット取得方針

本アプリは、チャット取得そのものを主目的とするアプリではありません。

ライブチャットの取得は外部チャット取得アプリケーションに一任し、本アプリは受け取ったコメントデータをもとに待機列を整理します。

本アプリの主な責務:

- 参加希望ワードの判定
- 取消ワードの判定
- NOW / NEXT / QUEUE の整理
- 管理画面での手動操作
- OBSブラウザソースへの表示

外部連携は、公式に許可された方法のみを使用します。

## Windows向け簡易起動（検証者向け）

- `start.bat` をダブルクリックすると、必要なら `.venv` 作成と依存インストールを行って起動します。
- 起動後、`http://127.0.0.1:8080/control` が自動で開きます。
- `run.bat` は開発者向けの簡易起動として残しています。


## SQLite保存先

- デフォルトDBファイル: `data/waiting_list.sqlite3`
- 環境変数 `WAITING_LIST_DB_PATH` で変更可能


## コメント受信API（MVP土台）

- `POST /api/comments/receive`: 外部チャット取得アプリケーションからHTTPでコメントを受け取る入口
- `POST /api/comments/manual`: 開発・検証・デモ用の手動コメント投入入口
- 本アプリは配信サイトAPIへ直接接続しない
- 受信APIレスポンスは `status` / `duplicate` / `command` / `declared_player_name` を返す
- 参加希望・参加辞退コメントは、受信後に待機列へ反映されます。
- 同じユーザーが再度 `参加希望` を送った場合、現在の参加枠を放棄して最後尾に並び直します。
- 申告名付きで再度参加希望した場合、申告名を更新したうえで最後尾に並び直します。

- 同じユーザーが参加希望・参加辞退・再度の参加希望を行った場合、状態変更後40秒間は次の状態変更が無視されます。
- ロック中に「参加希望 名前 たなかたろう」を再送しても、申告名は更新されません。
- /control からの手動削除・並び替え・申告名編集は40秒ロックの対象外です。
- 受付開始/終了、低消化回数優先切替、次の対戦に移る、リセットは `/api/control/*` を使います。
- `/api/mock/*` は開発・テスト用APIとして残します。
- 重複メッセージは `externalMessageId` により無視されます。
- コメント本文・`externalMessageId`・`userKey` 生値はSQLiteへ長期保存しない
- `/api/overlay-state` はOBS表示専用の最小レスポンスを維持する
- 「次の対戦に移る（参加回数+1）」操作で、現在対戦中グループの実在参加者の参加回数が +1 される
- 参加回数は `user_id` 単位で `participation_counts` としてSQLiteに保存され、再起動後も復元される
- 再度 `参加希望` した場合、保存済み参加回数が待機列表示と低消化回数優先に反映される
- 全リセットでは参加回数も初期化される


## 視聴者向けコメント操作

### 参加希望の出し方

```text
参加希望

申告名付き:

参加希望 名前 たなかたろう

説明:

参加希望 を含むコメントが参加希望として扱われる
名前 の後ろが本人申告のゲーム内名として扱われる
同じユーザーが再度 参加希望 を送ると、現在の位置を捨てて最後尾に並び直す
申告名付きで再度送ると、申告名を更新したうえで最後尾に並び直す
```

### 参加辞退の仕方

```text
参加辞退

または

参加を辞退

説明:

参加辞退 または 参加を辞退 を含むコメントが辞退として扱われる
キャンセル / 取消 / やめます / cancel は辞退として扱わない
```

### 反応しない例

```text
参加希望者
参加希望順
参加
さんか
join
参加します
参加したい
キャンセル
取消
```



## OBSでの操作方針

- `/overlay` は配信画面表示専用です（操作UIは出しません）。
- 受付開始/終了、低消化回数優先切替、次の対戦に移る、リセット、待機列の並び替え・削除・末尾移動・申告名編集は `/control` で行います。
- OBS上で操作したい場合は、`/control` を OBS のカスタムブラウザドックとして追加してください。
