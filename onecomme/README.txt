待機列整理アプリ・わんコメ版 1.1.0（Windows x64）

これは独立アプリ版1.1.3とは別系統です。実際のわんコメ9.1.1と配信での受信確認は未完了です。
対応はYouTubeのみ。わんコメ本体のインストーラー・SDKは同梱していません。

【初回導入】
1. ダウンロードしたZIPのプロパティで「許可する」が表示される場合はチェックして適用し、展開します。
2. わんコメ右上のメニュー → プラグイン → プラグインフォルダを開きます。
3. このsankagata-seiretsuフォルダを丸ごと配置します。plugin.jsとruntimeは分離しないでください。
4. プラグイン画面で再読み込みし「待機列整理アプリ」を有効にします。
5. プラグインのURLボタンから管理ページを開きます。
   http://localhost:11180/plugins/jp.kyo563.sankagata-seiretsu/index.html
   わんコメの標準APIポート11180を使用します。

【毎回の利用】
わんコメで配信に接続し、コメントを1件受信してください。
管理ページの「ライブ連携・わんコメ」で対象配信を選び「この配信から受信する」を押します。
受付中にしてから、新しい「参加希望」コメントで確認してください。
初回の過去コメントや選択前のコメントは参加登録しません。再起動後は配信を選び直します。
複数配信のコメントを混ぜないため、選んだ配信だけを処理します。
APIキーやGoogleログインは、このプラグイン側には入力しません。
限定配信はわんコメ側で取得できる必要があり、本版での動作は未検証です。

【画面とOBS】
管理ページはブラウザで開きます。わんコメ本体の一覧画面へ直接埋め込む機能ではありません。
1. 同梱のTaikiretsu-Template.zipを、わんコメのテンプレート一覧にドラッグ＆ドロップして追加します。
   管理画面「OBSに追加する」から同じZIPを保存することもできます。
2. 「待機列整理アプリ」の「ここをドラッグしてOBSに入れる」からOBSのシーンへ追加します。
3. OBSのブラウザソースの幅1200・高さ600以上を指定します。
4. 表示設定は管理画面で行い「保存してOBSに反映」を押します。テンプレートの交換は不要です。
縦向きは480×600、横向きは1200×240の領域へ自動切り替えします。OBSの枠は共通です。
改行・文言・名前の表示形式・フォント・色も共通の設定を反映します。
手動で表示領域を1200×600より大きくする場合は、OBSの枠も広げてください。
わんコメと本プラグインの起動が必要です。OBSを先に開いた場合、テンプレートは自動で起動を待ちます。
従来の http://127.0.0.1:18765/overlay も引き続き使用できます。
管理用URLはEdgeやOBSのカスタムブラウザドックで利用できます。他の人に共有しないでください。
ポート18765が他アプリで使用中の場合は起動できません。別アプリは停止・変更しません。
終了時は本プラグインを無効化するか、わんコメを終了してください。
ブラウザの管理ページを閉じただけでは受付処理は継続します。

【既存データ・更新】
保存先は %LOCALAPPDATA%\WaitingListAppOneComme です。
既存版の %LOCALAPPDATA%\WaitingListApp は読み書きしません。
引継ぎには既存版でJSONバックアップを保存し、わんコメ版の管理ページ「その他」から復元します。
既存版に戻す復元は自動では行いません。双方のバックアップを保管してください。
YouTubeの同じチャンネルIDは従来と同じ本人識別となり、復元した累計を引き継ぎます。
ハンドル・表示名だけで本人を推測しません。チャンネルIDを取得できないコメントは登録しません。
ハンドル情報が提供されない場合は表示名となります。実機のID・名前形式は要確認です。
全リセットでも累計は維持します。アップデートはプラグイン無効化後に本体フォルダを交換します。
登録フォントのデータはJSONバックアップに含まれないため、必要に応じて再登録します。

【完全削除】
先にわんコメで本プラグインを無効にし、裏側の処理が終了するまで15秒程度待ちます。
導入したsankagata-seiretsuフォルダを削除します。
本プラグインの保存データも不要な場合だけ %LOCALAPPDATA%\WaitingListAppOneComme を削除します。
わんコメ本体・他のプラグイン・OBS・Edge・既存版のWaitingListAppフォルダは削除しないでください。
OBSに自分で追加したソース/ドックは必要に応じてOBSから削除してください。
わんコメに追加した専用テンプレート「待機列整理アプリ」も不要なら削除します。他のテンプレートは削除しないでください。

【Botのお知らせ（任意・初期状態は無効）】
管理画面の「Botのお知らせ設定」で接続と各通知を設定します。
Bot専用YouTubeアカウントとデスクトップ用OAuthクライアントJSONが必要です。作成手順は設定画面にあります。APIキーでは投稿できません。
初回NOWが3人になったときと「次の対戦へ」で新NOWを案内します。Botの@ハンドルへのメンションに本人の待機順位を返信し、受付中は10分/30分ごとに設定文を投稿します。各機能を個別に無効化できます。
Botは認証したチャンネルIDで参加・辞退判定から除外します。ログイン情報はWindowsユーザーごとに暗号化し、bot.sqlite3へ保存します。待機列の全リセットやJSONバックアップの対象外です。
アプリの接続解除は保存した認証情報を削除します。Google側の許可はGoogleアカウントの接続管理から解除してください。
投稿はYouTube公式APIを利用します。わんコメ内への疑似コメントではありません。実アカウントでのログイン・実配信への投稿は未検証です。
